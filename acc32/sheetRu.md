## Acc32 Sheet

### Инструкции

| Инструкция | Смысл | Определение |
|---|---|---|
| `load_imm X` | `Acc ← X` | Поместить **само значение `X`** непосредственно в аккумулятор. |
| `load X` | `Acc ← Mem[PC + X]` | Загрузить значение из **относительного адреса памяти** в `Acc`. |
| `store X` | `Mem[PC + X] ← Acc` | Сохранить значение `Acc` в **относительный адрес памяти**. |
| `load_addr X` | `Acc ← Mem[X]` | Загрузить значение из **абсолютного адреса `X`** в `Acc`. |
| `store_addr X` | `Mem[X] ← Acc` | Сохранить `Acc` в **абсолютный адрес `X`**. |
| `load_acc` | `Acc ← Mem[Acc]` | Использовать текущее значение `Acc` как адрес памяти и загрузить значение по этому адресу. |
| `store_ind X` | `Mem[Mem[X]] ← Acc` | Использовать `Mem[X]` как адрес назначения и сохранить туда `Acc`. |
| `add X` | `Acc ← Acc + Mem[X]` | Прибавить значение из адреса памяти `X` к `Acc`. Обновляет `C` и `V`. |
| `sub X` | `Acc ← Acc - Mem[X]` | Вычесть значение из адреса памяти `X` из `Acc`. Обновляет `C` и `V`. |
| `mul X` | `Acc ← Acc × Mem[X]` | Умножить `Acc` на значение из адреса памяти `X`. Обновляет `C` и `V`. |
| `div X` | `Acc ← Acc / Mem[X]` | Разделить `Acc` на значение из адреса памяти `X`. |
| `rem X` | `Acc ← Acc % Mem[X]` | Вычислить остаток от деления `Acc` на `Mem[X]` и записать его в `Acc`. |
| `shiftl X` | `Acc ← Acc << Mem[X]` | Сдвинуть биты `Acc` **влево** на указанное количество позиций. |
| `shiftr X` | `Acc ← Acc >> Mem[X]` | Сдвинуть биты `Acc` **вправо**, сохраняя знак. |
| `and X` | `Acc ← Acc & Mem[X]` | Выполнить побитовое AND между `Acc` и `Mem[X]`. |
| `or X` | `Acc ← Acc \| Mem[X]` | Выполнить побитовое OR между `Acc` и `Mem[X]`. |
| `xor X` | `Acc ← Acc ^ Mem[X]` | Выполнить побитовое XOR между `Acc` и `Mem[X]`. |
| `not` | `Acc ← ~Acc` | Инвертировать каждый бит `Acc`. |
| `clv` | `V ← 0` | Сбросить флаг **Overflow**. |
| `clc` | `C ← 0` | Сбросить флаг **Carry**. |
| `jmp X` | `PC ← X` | Безусловно перейти на адрес `X`. |
| `beqz X` | `if Acc == 0 → PC ← X` | Перейти на `X`, если `Acc` равен нулю. |
| `bnez X` | `if Acc != 0 → PC ← X` | Перейти на `X`, если `Acc` не равен нулю. |
| `bgtz X` | `if Acc > 0 → PC ← X` | Перейти на `X`, если `Acc` больше нуля. |
| `bgez X` | `if Acc >= 0 → PC ← X` | Перейти на `X`, если `Acc` больше или равен нулю. |
| `bltz X` | `if Acc < 0 → PC ← X` | Перейти на `X`, если `Acc` меньше нуля. |
| `bvs X` | `if V == 1 → PC ← X` | Перейти на `X`, если установлен флаг Overflow. |
| `bvc X` | `if V == 0 → PC ← X` | Перейти на `X`, если флаг Overflow сброшен. |
| `bcs X` | `if C == 1 → PC ← X` | Перейти на `X`, если установлен флаг Carry. |
| `bcc X` | `if C == 0 → PC ← X` | Перейти на `X`, если флаг Carry сброшен. |
| `halt` | `STOP` | Остановить выполнение программы. |

## Символы и обозначения

| Символ | Определение |
|---|---|
| `Acc` | **Accumulator (аккумулятор)** — основной 32-битный регистр. |
| `Mem[X]` | Значение, хранящееся в ячейке памяти по адресу `X`. |
| `PC` | **Program Counter** — счётчик команд, указывающий адрес инструкции. |
| `C` | **Carry flag** — флаг переноса. |
| `V` | **Overflow flag** — флаг переполнения. |
| `←` | «получает», «присваивается» или «становится». |
| `+` | Сложение. |
| `-` | Вычитание. |
| `×` | Умножение. |
| `/` | Деление. |
| `%` | Остаток от деления (modulo). |
| `&` | Побитовое AND. |
| `\|` | Побитовое OR. |
| `^` | Побитовое XOR. |
| `~` | Побитовое NOT — инверсия битов. |
| `<<` | Сдвиг битов влево. |
| `>>` | Сдвиг битов вправо. |
| `==` | Равно. |
| `!=` | Не равно. |
| `>` | Больше. |
| `>=` | Больше или равно. |
| `<` | Меньше. |
| `→` | «Если условие истинно, то…». |

## Адресация

Это особенно важно для понимания Acc32.

| Запись | Что означает |
|---|---|
| `X` | Само значение или адрес `X`, в зависимости от инструкции. |
| `Mem[X]` | Прочитать значение из памяти по адресу `X`. |
| `Mem[Mem[X]]` | Прочитать значение из `Mem[X]`, использовать его как адрес и обратиться по этому адресу. |
| `PC + X` | Адрес, полученный относительно текущего `PC`. |
| `Acc` | Текущее значение аккумулятора. |

### Пример 1 — Immediate

```asm
load_imm 10
```

означает:

```text
Acc ← 10
```

То есть:

> Положить **само число 10** в аккумулятор.

---

### Пример 2 — Absolute Address

```asm
load_addr 10
```

означает:

```text
Acc ← Mem[10]
```

То есть:

> Перейти в ячейку памяти с адресом `10` и загрузить хранящееся там значение в `Acc`.

Например:

```text
Mem[10] = 50
```

после:

```asm
load_addr 10
```

получим:

```text
Acc = 50
```

---

### Пример 3 — Indirect Addressing

```asm
load_acc
```

означает:

```text
Acc ← Mem[Acc]
```

Например:

```text
Acc = 100
Mem[100] = 500
```

после:

```asm
load_acc
```

получим:

```text
Acc = 500
```

То есть:

> Значение `Acc` используется как **адрес памяти**.

---

### Пример 4 — Double Indirect

```asm
store_ind 100
```

означает:

```text
Mem[Mem[100]] ← Acc
```

Например:

```text
Acc = 25
Mem[100] = 500
```

тогда:

```asm
store_ind 100
```

сделает:

```text
Mem[500] = 25
```

Потому что:

```text
100
 ↓
Mem[100] = 500
 ↓
Mem[500] = Acc
```

# Главное, что нужно запомнить

```text
LOAD
Memory ───────→ Acc

ALU
Acc + Memory ─→ Acc

STORE
Acc ──────────→ Memory

BRANCH
Condition ────→ PC
```

И самая важная модель Acc32:

```text
             ┌─────────┐
             │   Acc   │
             └────┬────┘
                  │
        ┌─────────┼─────────┐
        ↓         ↓         ↓
      LOAD       ALU      STORE
        ↑         │         ↓
        └─────────┴────── Memory

                  │
                  ↓
               Branch
                  │
                  ↓
                 PC
```

**Коротко для защиты:**

> **Acc32 — accumulator-based architecture. Все основные вычисления выполняются через единственный основной регистр `Acc`. Данные загружаются из памяти в `Acc`, ALU выполняет операцию над `Acc`, результат остаётся в `Acc`, а при необходимости `Acc` сохраняется обратно в память. Условия переходов используют значение `Acc` или флаги `C` и `V`.**
